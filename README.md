# Portfolio d'Amath (Vue 3 + Vite)

## Lancer le projet
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # version de production dans /dist

## Personnaliser
- Tout le contenu (nom, email, projets, stats, compétences) : `src/data.js`
- Ta photo : mets `photo.jpg` dans `public/` puis `photo: '/photo.jpg'`
- Ton CV : mets `cv-amath.pdf` dans `public/`
- Captures de projets : champ `image` dans `src/data.js`
- Couleurs et polices : variables en haut de `src/style.css`
